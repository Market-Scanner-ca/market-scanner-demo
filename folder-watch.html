Folder watch: sample run

A contractor shares a Dropbox or Google Drive folder link for a project. Market Scanner lists it (names, sizes and dates only, no downloads), keeps a snapshot, and reports what changed and any new addenda. This sample uses a synthetic test folder.

1. First check

[sample] dropbox · ok · 2026-11-03T07:44:32-06:00
  4 files in 1 folders, 1,100,000 bytes; 1 addendum-like by name
  First snapshot stored; changes are reported from the next check.
    NEW ADDENDUM: /Specs/TST-100_Addendum_1.pdf

2. Next check: a new addendum and a changed spec section

[sample] dropbox · ok · 2026-11-03T07:44:32-06:00
  5 files in 1 folders, 1,149,411 bytes; 2 addendum-like by name
  Since last check: 1 new, 1 changed, 0 removed, 1 new addenda
    NEW ADDENDUM: /Specs/TST-100 Addendum 2.pdf
    new: /Specs/TST-100 Addendum 2.pdf
    changed: /Specs/Section 26 05 00.pdf

3. The contractor's link stops working

[sample] dropbox · expired · 2026-11-03T07:44:32-06:00
  link expired - ask the contractor for a fresh link (Dropbox shows 'Link Expired')
