What this is

Market Scanner turns a tender's documents into a one-screen bid / no-bid brief for electrical and instrumentation contractors. Every fact shows the exact quote, file and page it came from, and the build fails if a single quote is not found word for word. Missing facts say so instead of guessing.

These samples use public tenders only and a sample contractor profile.
