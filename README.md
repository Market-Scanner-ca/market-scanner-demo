# Market Scanner demo (static)

Built static files only: sample bid/no-bid briefs from **public tenders** (CanadaBuys open data, the Town of Outlook's public contract documents, and an owner-published addendum), extracted by AI (Gemini, free tier) with every fact quote-verified, the B19 Competition section from the Proactive Disclosure of Contracts dataset, and a folder-watch sample run on synthetic data. No client data.
